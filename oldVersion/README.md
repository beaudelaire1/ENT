# Anciennes versions et sources de migration

Ce dossier conserve les sources historiques sans les mélanger à la nouvelle
plateforme Django située dans `src/`.

- `django-initial/` : premier projet Django, base SQLite et environnement virtuel cassé ;
- `tempo-studio/` : application PySide6/QML servant de référence à Sablier ;
- `prototypes/` : prototypes HTML du suivi L3 ;
- `documents/` : documents personnels à réimporter lorsqu'ils sont disponibles ;
- `build-artifacts/` : anciens résultats de construction.

Le fichier `topo25.pdf`, présent pendant l'audit initial, n'était plus dans le
dossier au moment de l'archivage. La commande d'import le considère donc comme
optionnel et le mentionne dans son rapport s'il reste absent.
